# GOLD FUNDAMENTAL ANALYSIS

Fundamental analysis workspace for **XAUUSD**, focused on Fed policy path and gold price reaction.

## Scope
- Predict Fed rate **cut / hold / hike**
- Track FOMC decisions, minutes, and Fed speakers
- Map macro releases to expected **XAUUSD** movement

## Priority drivers for XAUUSD
1. FOMC decision + press conference
2. US CPI / Core CPI
3. PCE / Core PCE
4. NFP + Unemployment + Average Hourly Earnings
5. Fed speakers (Powell first)
6. Nominal yields + real yields + DXY
7. Geopolitics + central-bank gold buying / ETF flows

## Mandatory macro checklist (every plan)
Always read these **before** chart entries. Macro = bias. Chart = timing.

| # | Factor | What to track | Gold rule of thumb |
|---|---|---|---|
| 1 | **Inflation** | CPI, Core CPI, PCE, Core PCE, PPI | Hot inflation → hike odds up → usually bearish gold near-term |
| 2 | **Fed path** | FOMC decision, dots, FedWatch hike/hold/cut odds | Hike priced / hawkish → prefer sell rallies |
| 3 | **Nominal yield** | US 2Y + **10Y Treasury yield** | Rising nominal yields → bearish gold |
| 4 | **Real yield** | **10Y TIPS real yield** (and 5Y) | Rising real yields = strongest gold headwind |
| 5 | **Breakeven inflation** | 10Y breakeven ≈ nominal 10Y − real 10Y | Rising breakevens can support gold; falling can hurt |
| 6 | **Dollar (DXY)** | DXY trend/day change | Rising DXY → bearish gold |
| 7 | **Labor / growth** | NFP, unemployment, claims, GDP | Strong data → higher-for-longer → bearish gold |
| 8 | **Risk / flows** | Geopolitics, CB gold buying, ETF flows | Can cushion dips; rarely override rate path alone |

### Yield identity to always note
```text
Real yield ≈ Nominal yield − Inflation expectations (breakeven)
```
- If **nominal↑** and **breakeven flat/down** → real↑ → gold pressure
- If **nominal↑** only because **breakeven↑** → real may be flat → gold less hurt / can hold
- Best gold support: **real yields falling** + **DXY softening**
